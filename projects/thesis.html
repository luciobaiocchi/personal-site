Bachelor's Thesis Project

####Development of Intelligent Devices for Tracking and Communication Between Hiking Groups in Remote Environments #####Description The thesis presents the design and implementation of a distributed hardware–software platform that enables position tracking and message exchange between hikers in areas without cellular coverage. The system integrates an ESP32-based architecture with GPS modules, long-range LoRa transceivers, and low-power displays, focusing on energy efficiency and usability in emergency scenarios. A decentralized communication protocol is proposed to support dynamic network topologies, managing position updates, broadcast messages, and SOS alerts entirely peer-to-peer. A leader-election and synchronization mechanism is implemented to coordinate data collection rounds, minimizing transmission collisions while ensuring reliable propagation of positional information across the group. Objective: develop a decentralized LoRa-based positioning system for hikers, enabling robust peer-to-peer communication and cooperative safety features in remote outdoor scenarios. This thesis project focuses on the design and prototyping of a **modular device for mountain safety**, aimed at assisting hikers and mountaineers in remote environments.

Technologies used:

C++ (ESP32), LoRa, GPS module, OLED screen, accelerometer, barometer, and custom protocol design.

#####Heard Mobile Application Heard Mobile is a social platform and companion app dedicated to monitoring outdoor sports activities such as running and trekking. It allows users to record routes, speed, calories burned and other training metrics, analyse their performance over time, compare results with other athletes and share activities within a community. Is built to comunicate with the embedded device and visualize on the phone the position of other hikers in real time.

Technologies used:

  • Jetpack Compose → UI moderna e dichiarativa
  • Firebase
    • Auth → Autenticazione utenti
    • Firestore → Database NoSQL in Cloud
    • Analytics → Tracciamento eventi
  • Ktor & KotlinX Serialization → Chiamate API REST e parsing JSON
  • Koin → Dependency Injection semplice e modulare
  • DataStore → Persistenza dati locale e salvataggio preferenza tema
  • OSMDroid → Mappe OpenStreetMap
  • Coil → Caricamento immagini efficiente
  • YCharts → Grafici interattivi in Compose
  • Google Play Services → Accesso alla geolocalizzazione
  • Coroutines → Programmazione asincrona in Kotlin
